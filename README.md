# 婚恋数据核查台

一个纯静态的五页站点，托管在 GitHub Pages 上。

## 页面

| 文件 | 内容 |
| --- | --- |
| `index.html` | 首页。一句婚恋数据的「溯源核查」——对「25-35 岁男性无房无车相亲成功率 12%、有房后 45%」的完整回溯 |
| `anti-scam.html` | 独立专题「怎么防止自己被骗钱？」——识别三类情形、两条止损路径、可执行的取证细节 |
| `rules.html` | 独立专题「行动守则」——七条可直接执行的自我保护阈值，原文收录 |
| `expectations.html` | 独立专题「我想要的关系」——金钱与付出、情感与尊重、自我成长、底线原则四组约定 |
| `references.html` | 附录「资料库」——本站引用的外部视频与报道清单，**唯一的资料增长点** |

阅读顺序：溯源核查 → 防骗钱指南 → 行动守则 → 双向约定，资料库作为附录挂在最后。每页正文独立，首页与页尾只提供跳转入口，不混排内容。

## 扩展约定

新增一份**外部链接类**资料（视频、报道）：只在 `references.html` 加一条条目，不新增页面、不新增导航项。

新增一份**成篇文字**资料：才为它单独开一页，并回到 `references.html` 登记一条指过去，同时同步导航、页脚、跳转卡、`404.html` 与本文。

这样导航栏长度由「内容板块」决定，不随资料数量增长。

## 结构

```
.
├── index.html          # 溯源核查主页
├── anti-scam.html      # 防骗钱独立页
├── rules.html          # 行动守则独立页
├── expectations.html   # 双向约定独立页
├── references.html     # 资料库附录（持续新增条目）
├── 404.html            # GitHub Pages 自定义 404
└── .nojekyll           # 关闭 Jekyll 构建
```

无构建步骤、无外部依赖、无 CDN、无字体请求。每页的 CSS 与 JS 均内联，离线可用。外链一律 `target="_blank"` 且带 `rel="noopener noreferrer"`，链接失效不影响本站阅读。

## 本地预览

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000
```

或直接双击 `index.html`。

## 部署

Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后约一分钟内可访问 `https://<user>.github.io/<repo>/`。站点有 CDN 缓存，更新后需强制刷新（Ctrl+F5）才能看到新版。
